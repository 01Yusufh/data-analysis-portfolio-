# AnalystLab Africa Internship Projects

Welcome! This folder holds the projects I completed during my remote data analytics internship at AnalystLab Africa.

Each week came with a new dataset and a different business problem, so the work covers:

- 🐍 python
- 🗄️ sql
- 📈 power bi

## About the Internship

AnalystLab Africa is a remote data analytics internship where interns get a new analytics task every week. Over eight weeks, I worked through real-world style datasets: cleaning the data, exploring it, building dashboards, and writing up what the numbers say in plain language.

## What I Took Away

- I got more comfortable taking a project from raw data to a finished deliverable: cleaning and exploring the data, then building dashboards in Power BI with DAX measures, and writing the findings up in plain language.
- The churn analysis taught me to report what the data shows (for example, churn rates by contract type) without claiming to know the cause.
- Spending weeks 4 to 8 on one project, HealthConnect, gave me practice going deeper into a single dataset instead of moving on after the first pass.
